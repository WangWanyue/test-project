# Hello World Android App

A simple Android application that displays "Hello World!" on the screen.

## Features

- Clean, modern UI with a centered "Hello World!" message
- Light gray background with a white text box
- Blue text color for better visibility
- Material Design elevation for a modern look

## How to Run

1. Make sure you have Android Studio installed
2. Open the project in Android Studio
3. Connect an Android device or start an emulator
4. Click the "Run" button (green play icon) or press Shift+F10
5. The app will install and launch on your device/emulator

## Project Structure

- `app/src/main/java/com/example/drawingapp/MainActivity.java` - Main activity that handles the app lifecycle
- `app/src/main/res/layout/activity_main.xml` - Layout file defining the UI
- `app/src/main/res/values/strings.xml` - String resources
- `app/src/main/AndroidManifest.xml` - App manifest file

## Requirements

- Android API level 21 (Android 5.0) or higher
- Android Studio 4.2.0 or higher
- Gradle build system
